# Comment Reply Notify

Emails commenters when someone replies to their comment — the simplest way
to bring people back to a conversation.

## Features

- **Opt-in checkbox** on the comment form ("Notify me when someone replies
  to my comment"). Logged-in users are checked by default.
- **Approved replies only** — notifications fire on the transition to
  `approved`, so spam and pending comments never trigger an email.
- **No self-notifications** — replying to your own comment sends nothing.
- **One-click unsubscribe** — every email carries a signed link that
  removes just that comment's subscription, no login required.
- **No settings page** — nothing to configure; it works on activation.

## Installation

1. Upload the plugin folder to `wp-content/plugins/`.
2. Activate it.
